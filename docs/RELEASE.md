# macOS Apple Silicon 预览版

## v0.3.0 双应用交付

本次交付包含两个独立的 macOS 应用和 DMG：

| 安装包 | 应用 | 用途 |
| --- | --- | --- |
| `AVDM-0.3.0-mac-arm64.dmg` | AVD 多开管理器 | Android SDK、模拟器实例、实时画面和设备操作 |
| `Wanlong-Assistant-0.3.0-mac-arm64.dmg` | 万龙助手 | 连接本机实例，运行万龙觉醒助手流程 |

按需安装其中一款或两款。助手与多开管理器共用 `@avdm/core` 和 `~/.avdm`，无需让多开管理器窗口常驻；助手需要本机已有兼容 SDK、实例和游戏。两个应用各自有图标、进程和应用标识，可独立更新。下载后分别打开 DMG，将 App 拖入“应用程序”。安装版无需 Node.js 或 pnpm。源码结构与跨应用调用方式见 [双应用架构](APPLICATIONS.md)。

模拟器现为纯设备管理产品：SDK 安装、实例生命周期、实时画面、设备设置及 `avdm` CLI 均可独立使用。万龙助手在单独目录和安装包中提供账号与实例绑定、交互式登录、采集调度、可编辑视觉模板、脚本与北京时间任务计划、运行统计、异常告警、本地和 Telegram 通知、Telegram 机器人（查看状态与截图 / 远程暂停、恢复、重启游戏与读资源，两个开关默认都关）及 AI 画面顾问。脚本编辑器支持从画面截取模板并自动插入点击或等待功能块；复杂条件和循环可用高级 JSON 编辑。助手通过 `@avdm/core` 调用同一批实例；通用 Electron 能力放在 `@avdm/emulator-shell`，方便后续增加其他游戏助手。旧脚本和计划 JSON 可在“计划与脚本”页选择导入，旧计划导入后默认关闭执行。

模拟器安装包内附带 `avdm` 命令行和运行时：`'/Applications/AVD 多开管理器.app/Contents/Resources/bin/avdm' --help`。安装过程不修改系统 `PATH`；如需简写命令，可自行建立指向该文件的符号链接。

自动操作初始关闭。旧版 MuMu 专用重启逻辑未用于当前官方 Android Emulator；卡死与疑似顶号先生成只读告警。顶号识别需要用户保存相应的画面模板。真实 #1 已验证模拟器启动、ADB 列表、截图及优雅关机；新版账号登录、真实派兵、脚本计划、Telegram 网络收发与外部 AI 服务仍需在用户配置对应账号、模板、Token 或模型后做实机验收。

安装包使用临时签名，尚无 Developer ID 签名和公证；macOS 可能阻止首次打开，需要在“系统设置 → 隐私与安全性”中允许打开。仅支持 Apple Silicon；安装包不含 Google SDK、系统镜像、游戏 APK、私有模板或账号数据。首次配置可在多开管理器的 SDK 向导中完成。

## 万龙助手的应用内更新

设置页「版本与更新」卡片和左下角版本号（有新版本时带红点）都能检查更新。助手启动 30 秒后会自动检查一次，只读取发布信息；下载和安装都要手动点击。

更新流程：

1. 助手读取 GitHub `TgolMsk/AndroidAutomation` 的 Release 列表（包括预览版），找到版本最高、带 `Wanlong-Assistant-<版本>-mac-arm64.dmg` 的发布，并显示更新说明。
2. 点击「下载更新」，安装包会下载到「下载」文件夹；如果 macOS 不允许助手访问「下载」文件夹，会改存到临时文件夹（面板上会显示完整路径，也可以点「在访达中显示」）。下载先写入 `.part` 文件，中断后再点会从断点继续。下载完成后，用同一 Release 的 `SHA256SUMS` 校验，通过才会保存为 `.dmg`。
3. 点击「退出并打开安装包」，助手会先确认没有采集、脚本计划、账号登录或 SDK 安装正在进行，再复核一次安装包。然后打开 DMG 并退出助手。
4. 把「万龙助手」拖到「应用程序」，选择「替换」，再重新打开助手即可。

以下内容不受替换影响：账号、模板、计划和统计（都在 `~/.avdm`）、模拟器实例。已开启的自动续跑会按原设置恢复。

安装包没有 Apple Developer ID 签名，只有临时签名。Squirrel.Mac 无法校验新版本，因此不能像 Windows 版万龙面板那样静默替换自身，需要手动拖动一次。以后如果改用开发者签名和公证，可以再换成自动安装。

发布时要满足以下约定，助手依赖它们：

- 标签为 `v<版本>`，与两个应用的 `package.json` 版本一致（工作流已校验）。
- Release 附件名必须是 `Wanlong-Assistant-<版本>-mac-arm64.dmg`。
- `SHA256SUMS` 里必须有 `wanlong-assistant/Wanlong-Assistant-<版本>-mac-arm64.dmg` 这一行。助手按文件名查找，工作流已校验这一行存在。
- 预览版（prerelease）也会推送给用户。只想内部测试的版本请用草稿（draft）发布。

排查问题：更新的每一步都写进助手的运行日志 `~/.avdm/automation/logs/app.ndjson`（来源为 `update`），也可以在助手「设置 → 日志」里按来源 `update` 筛选查看。检查和下载失败一定会记录；想看每一步，把「日志记录级别」调到「信息」。随时可以点「打开 Release 页面」手动下载。

## 上一版：v0.2.0

桌面界面改为深色专业风格，更新应用图标、实例墙和操作层级。新增游戏自动化工作台：可对运行中的实例选择私有模板目录，在独立工作线程读取前台应用与原始截图，并显示万龙觉醒模板的逐项匹配分数。万龙觉醒的 G0–G16 采集流程可单轮运行，也可按 ETA 自动续跑；按实例保存状态、运行记录和唤醒时间，支持取消、重启恢复与连续失败自动暂停。默认关闭采集，启动前要确认前台游戏和高分场景锚点。模板图片、游戏账号和设备数据不随安装包发布。

真实 #1 已通过城内到世界地图的无派兵单轮验证（`dispatched=0`）。真实派兵、兽族 B 版和长期自动续跑尚未完成验收；先在测试实例使用采集功能。旧 `wanlong-panel` 的账号登录、通知、AI 顾问、统计和模板编辑仍未移植。

下载 `AVDM-*-mac-arm64.dmg`，打开后将“AVD 多开管理器”拖到“应用程序”，再启动应用。安装包自带桌面客户端，不需要安装 Node.js 或 pnpm。

首次在没有 Android SDK 的 Mac 上启动时，应用内会打开 SDK 向导。阅读并同意相应许可后，向导从 Google 下载约 1.1 GB 的 Android Emulator、Platform-Tools 和 ARM64 系统镜像。下载完成后在主界面创建实例即可使用；已有兼容 SDK 的 Mac 可以直接使用。

当前预览包使用临时签名，没有 Developer ID 签名和公证。macOS 可能阻止首次打开，需要在“系统设置 → 隐私与安全性”中允许打开。安装包只支持 Apple Silicon，不包含 Google SDK 或系统镜像，也不包含游戏 APK。
