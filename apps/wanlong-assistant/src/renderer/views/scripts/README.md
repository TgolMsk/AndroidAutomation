# 脚本页（可视化块编辑器）`views/scripts/`

移植自 wanlong-panel 的 `views/ScriptsView.tsx`、`features/blocks/BlockEditor.tsx`、`features/blocks/CaptureBlockModal.tsx`，
纯逻辑在 `@avdm/automation/script` 的 `blocks.ts`（块树、块目录、摘要、黄标，对照只有这一份）。

| 文件 | 内容 |
| --- | --- |
| `ScriptsView.tsx` | 脚本列表（名字 / 版本 / 步数 / 包名 / 模板集；内置示例不可删、保存即「另存为副本」；删除要确认；导入旧脚本 JSON）+ 编辑区（可视化 / JSON 切换、校验 / 保存 / 格式化 / 试跑、问题列表点一下定位到块或 JSON 里的 id、未保存标记、坐标说明）+ 脚本头部（名字、模板集 + 就地新建、目标应用只读、跑完再来一轮 + 间隔） |
| `BlockEditor.tsx` | 递归块列表：卡片默认折叠成一句话、单选展开表单、任意层级上移 / 下移 / 复制 / 删除、if / loop 分支缩进、往分支加块、加「否则」分支、分组的「加一块」菜单 |
| `StepFields.tsx` / `fields.tsx` | 17 种块的表单与「更多设置」（名字、前置条件、重试、失败处置、超时、做完再等、强制留痕、单块 JSON）；条件编辑器（不设 / 画面上有 / 画面上没有 / 出现任意一张 / 前台应用是 / 总是成立，组合条件只读） |
| `CaptureBlockModal.tsx` | 「从画面截取一块」：选已开机实例 → 抓一帧 → 拉框（≥8×8）→ 选块类型 → 起名（≤40 字、回车保存）→ 存模板（**不传 defaultRoi**，note「在脚本编辑器里截取」）并插块 |
| `script-editor.ts` | 纯函数：文本解析（含块树结构检查）、页面派生值 `draftView`（绝不抛）、模式记忆、保存闸门、定位、模板集合并、插入位置与**防过期插块** |
| `VisualGuard.tsx` | 手改 JSON 缺字段时，可视化模式只显示提示，不让整页崩掉 |

铁律（原版 CLAUDE.md「可视化脚本编辑器」五条）：
1. **单一数据源是 JSON 文本**。可视化的每次改动都序列化回文本，两种模式来回切永不丢改动；页面不另存一份脚本对象。
   JSON 模式接受任何文本：能解析但块树不完整（缺 id、循环缺 steps、条件分支缺 then、空块、粘贴的半截）时，页面派生值照常算出（`draftView`），
   只是可视化模式不接、提示去 JSON 模式修；整页绝不因此崩掉丢草稿。单块 JSON 编辑也按同一条结构检查（`blockShapeProblem`）才生效。
2. 块树操作一律返回新数组；路径失效（刚删过块又点了旧按钮）原样返回。选中按块 id 记，移动后自动跟随。
3. 复制用 `cloneWithNewIds`，子块 id 也全换，否则保存报「步骤 id 重复」。
4. 截取存模板不传 defaultRoi；`TEMPLATE_LOW_VARIANCE` 翻成「换一块有图标、有文字、有明显边缘的区域」。
5. 组合条件（and / or / not / never）只读，提示去 JSON 模式改，不做可视化表达式树。

助手特有的边界：
- 模板只能存进**实例正在用的模板集**（运行时也用它，`script-worker-core` 会拒绝不一致的模板集），所以截取弹窗只在实例的模板集就是脚本的模板集时允许保存；
  不一致时可以一键把脚本改用实例的模板集，或到「模板库」切换实例。保存结果回来后再按脚本 id + 模板集核对一次才插块（防过期）。
- 保存模板与在模板库保存一样会关掉该实例的自动续跑，页面随后通知采集页重新探针（`noteTemplateChanged`）。
- 「＋」就地新建模板集走 `createAutomationTemplateSet`，会把当前实例切到新模板集（先确认）。
- 启动 / 关闭 / 前台条件只允许当前游戏包，表单只读显示；中文输入需要实例装好并启用 ADBKeyboard。
- 保存：结构性错误拒绝写盘；其余错误可存为草稿但不能运行（与脚本引擎的三级校验一致）。
